01

最终结论

reward 接通了，但大部分题组仍没有可用的相对学习信号。

152/ 200 题组 zero advantage

只有 48 个题组的累计 reward 不完全相同。其中又有 26 个题组的答案 EM 与 Token F1 完全一致，reward 差异仅来自 evidence ref、格式或过程惩罚。

真正出现答案 F1 差异的题组只有 22 个，占 11%。因此直接训练会让多数计算落在零梯度组上，少数梯度也不一定在优化最终答案。

02

实验设计与边界

这是一轮训练信号诊断，不是完整端到端检索 benchmark。

固定模型

Qwen3-4B Hybrid + Format step-100 checkpoint。

固定数据

同一份 Eval-200，文件 SHA-256 以 f1f7cc57 开头。

独立采样

每题 4 个独立 rollout seed，temperature=1.0。

Gold evidence

Gold supporting facts 只进入 oracle 环境与 scorer，不向模型注入 gold answer。

不能直接与此前 greedy baseline 横向比较：本轮换成 Evidence V2 action contract、gold evidence oracle 和随机 n=4 采样。它回答的是“有没有 GRPO 信号”，不是“新 harness 是否提高线上 EM”。

07

下一步：先补能力，再重新过 gate

继续调 reward 权重无法让模型学会当前不会的关系执行。

  1. 自动构造 Evidence-State SFT。从 HotpotQA supporting facts 与 gold answer 生成 sufficient / insufficient、selected refs 和最小答案，不需要人工标注。
  2. 加入 question-type answer contract。Comparison 明确执行比较并输出 yes/no；Bridge 输出实体或最小 span。
  3. 重跑同一 Eval-200 × n=4。保持数据、seed 规则、temperature 和 scorer 不变，重新测 zero-advantage 与 answer-F1 variance。
  4. 满足门禁后再开 GRPO。优先观察答案质量差异，而不是只看 evidence 或格式产生的 reward variance。
