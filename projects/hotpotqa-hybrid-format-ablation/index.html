E1 · Controlled reward ablation

加上格式奖励，模型真的更好吗？

20题验证曾显示 EM 从 25% 升到 30%，但这只相当于多答对一道题。我们把两个 step-100 checkpoint 放进固定 Eval-200，用同一解析器和逐题配对统计重新回答这个问题。

Evaluation set200 · 100 bridge + 100 comparison
InferenceGreedy · n=1 · seed 42
Compared modelsHybrid vs Hybrid + Format · step 100
01

格式约束有效，答案能力没有提升

Format reward 做到了它该做的事：减少不合法 final answer，同时没有损伤 EM 和 Token F1。它不是新的推理能力来源，也不能被表述为 HotpotQA 准确率提升。

Exact Match55.0% = 55.0%

两个 checkpoint 都答对 110 / 200 题。

Format Valid91.5% → 94.5%

严格格式多通过 6 条，提升 3 个百分点。

Malformed17 → 11

格式失败减少 35.3%，但仍有 5.5% 未解决。

Extra Searches0.19 → 0.37

额外搜索接近翻倍，证据召回仅小幅变化。

可对外使用的结论

在固定 HotpotQA Eval-200 上，format-aware hybrid reward 将严格格式正确率从 91.5% 提升到 94.5%，同时 EM 保持 55.0%。这是协议合规改进，不是任务准确率改进。

02

只改变最终答案的格式约束

两个训练实验都使用 Qwen3-4B、Agent-R1 + veRL、100 step、batch 4、每题 4 条 rollout 和 seed 42。内容奖励的 EM/F1 权重一致，新增变量是严格格式 gate 与 0.1 格式分。

Hybrid

answer_score = 0.2 * EM + 0.8 * TokenF1
train_reward = answer_score

能给部分正确答案密集反馈，但不会惩罚缺失、重复或尾随内容的 answer tag。

Hybrid + Format

if strict_format_invalid:
    train_reward = 0
else:
    train_reward = 0.9 * answer_score + 0.1

合法输出得到小额格式分；格式不合法时整条 trajectory 的最终 reward 归零。

两个 step-100 checkpoint

分别来自无格式奖励与 format-aware reward 的 GRPO 训练。

固定 Eval-200

统一计算 EM、F1、严格格式、证据召回、工具成本、CI 与 McNemar 检验。

为什么不比较训练 reward

两种 reward 的数值刻度不同。训练 reward 高低不能跨公式直接比较，最终判断必须落到同一 held-out harness 的任务指标。

20题小样本给出的错觉

20题上 EM 从 25% 到 30% 看起来提升 5 个百分点，本质只是多答对 1 题。扩展到 200 题后，两者都是 110 题正确。这就是固定大样本 harness 的价值。

05

新的问题定义

格式问题已经被压到次要位置。Bridge EM 只有 47%，而 comparison 达到 63%。下一步应分析多跳检索是否找到两条必要证据，以及搜索 query、工具次数与最终答案之间的信用分配。

06

07

这次实验真正教会了什么

价值不在于制造一个“指标上涨”的故事，而在于把 reward、训练信号、held-out 质量和系统成本拆开。

Reward 是行为约束，不是能力注入

模型会更遵守 answer tag 协议，但不会因为 0.1 格式分自动获得更强的多跳推理能力。

更多有效梯度不等于更好泛化

Zero-advantage step 从 41% 降到 31%，有效更新由 59 增至 69 次，但 Eval-200 EM 仍然相同。

小验证集适合 Debug，不适合决策

20题能快速发现 schema、parser 和流程错误；模型优劣必须回到固定200题的 paired harness。

下一实验方向

保留 format reward 作为协议约束，不再继续堆格式权重。下一轮围绕 bridge failure 做检索轨迹审计，检查 supporting-fact coverage、query novelty、无效搜索和 step-level credit assignment。

实验边界

这是单 seed、100-step 的受控 ablation，不是多 seed 显著性证明，也不是 HotpotQA SOTA 复现。CI 描述的是当前200题的逐题 bootstrap 不确定性，不能替代独立训练重复。

09

面试中如何讲这次 reward ablation

重点不是“我加了一个 format reward”，而是如何从小样本现象走到可验证结论。

我先用 EM + Token F1 缓解 HotpotQA 的稀疏奖励，
但在固定验证中观察到格式回归，因此加入 strict-format gate。

20题短评测看起来 EM 提升了 5 个百分点，
但我没有直接把它当作收益，而是将两个 step-100 checkpoint
放入固定 Eval-200 做 greedy、逐题 paired evaluation。

最终两个模型 EM 都是 55%，F1 也几乎一致，
但格式正确率从 91.5% 提升到 94.5%，格式错误从 17 条降到 11 条。

因此我的结论是：format reward 是有效的协议正则项，
但不是推理能力增强手段。下一阶段应处理 bridge 检索与信用分配，
而不是继续调高格式权重。
这段故事的工程含量

它同时覆盖 reward design、small-eval variance、held-out paired evaluation、统计边界、failure taxonomy 和 tool-cost trade-off，比单报一个训练 reward 更接近工业后训练工作。
